# MedRAG
MedRAG is a medical question-answering system built using Retrieval-Augmented Generation (RAG).
It retrieves relevant medical context from a dataset and generates accurate answers to user queries.

# Tech Stack
1. Python
2. LangChain
3. FAISS
4. Sentence Transformers
5. HuggingFace
